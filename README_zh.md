# 能量之战 - 重制版 (Energy Battle - Remake)

🌐 [English](README.md)

**能量之战 - 重制版** 是一款基于命令行终端（CLI）的回合制多人对战策略游戏，使用 Python 编写。游戏由自研的 **Noah 游戏内核 (Noah Kernel)** 驱动，支持复杂的多智能体战斗，允许人类玩家与多个 AI 玩家在立体的战场中展开大混战或团队对抗。

## ✨ 核心特性

- **回合制策略博弈：** 巧妙管理你的生命值 (HP)、能量和空间位置（楼层），以智取胜。
- **丰富的行动指令：** 包含互相克制的深度战斗系统，行动包括：*充能*、*射击*、*防御*、*移动*、*反射*、*能量波* 和 *黑洞*。
- **Noah 内核与 Ark 前端：** 坚固且高度模块化的架构，专为易扩展性设计。
- **局内模组与设置：** 支持在游戏内动态修改对战规则（如血量、地图大小、AI 组队模式），并支持模组 (Mod) 的热插拔。
- **沉浸式终端 UI：** 具备打字机文本动效、ANSI 色彩高亮显示，以及自动折叠的战报系统。
- **多语言支持：** 原生支持简体中文、繁体中文、英文和日文。

## 📋 运行要求

- 必须使用 **Python 3.12 或更高版本**。
- 一个支持 ANSI 色彩显示的终端/命令行工具（绝大多数现代 Windows, macOS 和 Linux 终端均支持）。
- 纯 Python 标准库开发，**无需**安装任何第三方依赖！

## 🚀 安装与运行

1. 克隆本项目仓库：
   ```bash
   git clone https://github.com/Ryzdump/energy-battle-remake.git
   ```
2. 进入项目目录：
   ```bash
   cd energy-battle-remake
   ```
3. 运行 Ark 前端启动游戏：
   ```bash
   python ark.py
   ```
   *(启动后，系统会提示您选择首选语言。)*

## 🎮 怎么玩

在默认设置下，游戏将安排 1 名人类玩家与 9 名 AI 玩家进行各自为战的大乱斗。

在每个回合中，你需要输入相应行动的编号来下达指令。如果你不输入任何内容直接按下 `Enter`（回车键），你的 AI 助手会自动替你做出当前最优的决策。

### 核心资源：
- **血量 (HP)：** 归零时您将被淘汰出局。
- **能量 (Energy)：** 用于发动攻击和高级技能，通过*充能*获取。
- **位置 (Position)：** 战场由多个垂直楼层组成。你必须选择正确的射击方向（向上、平射、向下）且目标在射程内，才能命中敌人。

### 基础行动 (消耗)：
1. **充能 (+1 能量)：** 向真空借取能量。
2. **射击 (1 能量/发)：** 瞄准目标，最多可同时射出 3 发能量。
3. **防御 (0 能量)：** 在本回合内抵御受到的攻击伤害。
4. **移动 (1 能量)：** 改变你的垂直位置，用于躲避或追击。
5. **反射 (2 能量)：** 将受到的攻击伤害全数反弹给攻击者。
6. **能量波 (6 能量)：** 极具破坏力的范围攻击 (AoE)。
7. **黑洞 (5 能量)：** 直接吞噬并废除目标玩家本回合的行动。

*(您可以在游戏内选择“查看游戏说明”以获取更详细的规则和机制解释)。*
